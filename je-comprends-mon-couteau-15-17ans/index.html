Je comprends mon couteau (15-17ans)

Je comprends mon couteau

Ce que je vais apprendre

Derrière chaque couteau se cachent des choix techniques, des savoir-faire artisanaux et une histoire.

Défis

Comment un couteau est-il fabriqué ?

Découvrir :

  • la lame ;
  • le manche ;
  • le système de verrouillage ;
  • les matériaux ;
  • les étapes de fabrication.

Pourquoi ces matériaux ?

Comparer :

  • acier inoxydable ;
  • acier carbone ;
  • bois ;
  • matériaux composites.

Quels sont leurs avantages et leurs limites ?

Réparer plutôt que remplacer

Étudier un couteau usé.

Questions :

  • Peut-il être réparé ?
  • Que faut-il entretenir ?
  • Que faut-il remplacer ?

Le couteau et l'histoire du territoire

Découvrir :

  • les anciennes forges ;
  • le travail du fer ;
  • les métiers liés à la forêt ;
  • l'évolution des outils à travers le temps.

Projet final

Concevoir le cahier des charges du « couteau de Puisaye ».

Préciser :

  • l'usage ;
  • la forme de la lame ;
  • la longueur ;
  • le matériau du manche ;
  • le système de fermeture ;
  • les décorations ;
  • les symboles du territoire.

Présenter puis défendre ses choix.

Ce que je retiens

✅ Je comprends les choix techniques qui se cachent derrière un couteau.

✅ Je sais évaluer la qualité d'un outil.

✅ Je privilégie l'entretien, la réparation et la transmission.

✅ Derrière chaque couteau se trouvent un savoir-faire, un territoire et une histoire.
